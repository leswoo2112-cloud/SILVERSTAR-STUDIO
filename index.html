안내

실버스타 스튜디오 사용법

  1. 시작 화면에서 노래 제목·작곡자·장르를 선택하세요.
  2. 악기를 추가하고 편집할 마디를 선택하세요.
  3. 음표 길이·강도·표현을 고르세요.
  4. 악보나 격자의 원하는 위치를 눌러 입력하세요.
  5. 기존 음을 누르면 선택돼요. 설정 적용 버튼으로 수정하세요.
  6. 음을 옮길 때는 선택·이동 도구를 사용하세요.
  7. 화음을 만들려면 음 쌓기 또는 화음 도우미를 사용하세요.
  8. 음 강도 막대와 악기별 음량으로 균형을 조절하세요.
  9. 전체 곡 또는 선택 구간을 들어보세요.
  10. 편집 파일은 프로젝트 저장, 음원은 WAV 내려받기를 사용하세요.

노트북 단축키

  • 스페이스: 재생 / 정지
  • Ctrl 또는 Command + Z: 되돌리기
  • Ctrl 또는 Command + Shift + Z: 다시 실행
  • Delete 또는 Backspace: 선택한 음 삭제

아이패드 조작

손가락이나 애플펜슬로 입력할 수 있어요. 악보를 이동할 때는 여백을 스크롤하고, 음을 옮길 때는 선택·이동 도구를 사용하세요.

소리와 저장

소리는 재생 버튼을 누른 뒤 시작돼요. 내장 악기는 합성음이며 실제 악기 녹음과 차이가 있어요. 작품은 파일로도 저장해 두세요.
